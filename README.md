# SARCADE Server

Backend open source de la plateforme SARCADE : cartographie, coordination terrain, communications et Search & Rescue.

## Objectif V0.1
Permettre à un PCO de créer un événement, gérer équipes et utilisateurs, recevoir les positions terrain, partager messages et POI, fonctionner lors d'une perte Internet puis resynchroniser les données.

## Architecture cible
- API backend
- PostgreSQL / PostGIS
- WebSocket pour le temps réel
- MQTT pour les échanges asynchrones et Gateways
- déploiement conteneurisé
- fonctionnement Internet ou réseau local sans Internet
